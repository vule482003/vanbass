# VanBass Music Center

VanBass Music Center is a web platform for VanBass Music Center, focusing on DJ equipment, audio equipment, product rental, and product sales.

## Project Status

The project is currently in the initial setup phase.

Current development environment:

- Git
- GitHub
- Node.js
- pnpm
- Python
- uv
- Docker
- Docker Compose
- Visual Studio Code
